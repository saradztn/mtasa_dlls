# ProjectSquidArena

مورد MTA قابل للبناء يضم ساحتي لعب مستقلتين: **شد الحبل ضد فريق AI** و**جسر زجاجي ضد متسابق AI**. يولّد المشروع مجسمات ثلاثية الأبعاد فعلية بصيغ RenderWare DFF وCOL وTXD؛ ليس المشهد صورة أو مجسم Blender ثابتاً.

## البناء والتثبيت على Windows

1. ثبّت Python 3.9+ مع `python` و`pip` في PATH. الاتصال بالإنترنت مطلوب لأول بناء لتنزيل الحزم من PyPI.
2. افتح CMD أو PowerShell في مجلد `ProjectSquidArena` وشغّل:

   ```powershell
   python build.py
   ```

3. بعد ظهور `BUILD SUCCESS` انسخ `output/ProjectSquidArena` إلى مجلد `mods/deathmatch/resources/` على خادم MTA.
4. شغّل المورد من كونسول السيرفر: `start ProjectSquidArena`.

يولّد البناء هندسة DFF/COL، عشرة خامات DXT داخل TXD وخرائط المصدر (Albedo/Normal/Roughness/AO)، ينشئ `meta.xml`، ثم يفحص الملفات الثنائية ومراجعها وتحليل Lua/XML قبل ترقية مجلد الناتج. تقرير البناء في `build-report.json`.

## اللعب ضد AI

- `/squid` — المساعدة.
- `/squid tug` — شد الحبل ضد ثلاثة Peds AI. استمر بالضغط على Space أو زر الفأرة الأيسر. القوة والنتيجة يحسبهما الخادم.
- `/squid bridge` — سباق الجسر. استخدم A/D أو الأسهم لاختيار اليسار/اليمين، أو `/panel left` و`/panel right`.
- `/squid ai` — اطلب نصيحة رفيقك؛ يخطئ أحياناً عمداً (مهارة افتراضية 79%).
- `/squid leave` — مغادرة الساحة واستعادة موقعك/البعد السابق.
- `/squidfx low|high|cinematic` — إعداد المؤثرات المحلي.

تُدار الجولة ومصفوفة الألواح الآمنة والنتيجة على الخادم. في شد الحبل تضيف مدخلات اللاعب قوة مقابل ضغط AI؛ في الجسر يُحسم كل اختيار خادمياً، ويُقارن تقدّم اللاعب بالمتسابق الآلي. الـPeds تمثيل مرئي للخصوم/الرفيق، بينما سلوك AI وقواعد الفوز ليست مبنية على ادعاء ملاحة NPC ذاتية.

## ضبط الموقع

المصدر المركزي للإعدادات هو `config.py`: موضع الأصل العالمي، الأبعاد، نقطة دخول كل ساحة، حجم فريق شد الحبل ومهارة AI. الإحداثيات المحلية للمجسمات بالمتر، نظام GTA/RenderWare هو XYZ وZ للأعلى. كل بناء يعيد توليد `resource/shared/config.lua` من الإعداد المركزي.

## التقنية والجودة

- 19 نموذجاً وحدوياً مولّداً، 840 موضعاً في الساحتين، و36 لوح زجاجي فعلياً.
- DFF/COL حقيقية، TXD بصيغة DXT مع mipmaps؛ خامات الزجاج شبه شفافة.
- الخرائط الطبيعية مولّدة من Python/Pillow؛ shader السطح/الزجاج يستخدم لقطة شاشة مع Fresnel وroughness/jitter. هذا **تقريب Screen-Space** وليس ray tracing أو انعكاسات فيزيائية.
- خرائط Normal/Roughness/AO تُولّد وتُحفظ كمصادر أدوات؛ لا يقرأ MTA خصائص PBR القياسية منها مباشرة. تأثير السطح يعاد تركيبه في HLSL متوافق مع DX9 قدر الإمكان.
- الأشرطة emissive تزيد سطوعها ولا تدعي إنارة ديناميكية حقيقية. لا توجد ظلال ديناميكية أو global illumination مضمونة.
- شاشة البناء الحالية Linux ولا تحتوي MTA/DirectX/Blender؛ اختبارات DFF/COL/TXD وXML وتحليل Lua نجحت، لكن **لم يجر اختبار shader compile أو تحميل المورد داخل اللعبة**.
