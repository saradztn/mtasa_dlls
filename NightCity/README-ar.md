# NightCity — مدينة مستقبلية ضخمة ومتنوّعة (مورد MTA:SA)

مورد جاهز لـ **Multi Theft Auto: San Andreas**: مدينة مساحتها **1394 × 1622 م** بشبكة طرق غير منتظمة، أحياء سكنية وصناعية وترفيهية، سوق قديم، ميناء، حرم جامعي/مستشفى، نهر وجسور وطريقان سريعان معلّقان ونفق. لا يتضمن أشخاصاً أو مركبات أو حيوانات.

الذي تحتاجه فقط هو المجلد **`resource/NightCity/`**. انسخه إلى مجلد موارد السيرفر ثم شغّله. ملفات `source/` هي المولّد وأدوات التحقق.

```
NightCity/
  resource/NightCity/      <- المورد الجاهز للتشغيل
    meta.xml  client.lua  server.lua  tour.lua  atmo.lua  wet.fx  post.fx
    models.lua  layout.lua  sprites.lua
    files/                  <- نماذج DFF/COL، خامات TXD، صور وأصوات
  source/                  <- build.py وأدوات التحقق ومصادر النماذج والخامات
```

## التركيب والاستخدام

1. انسخ `resource/NightCity` إلى `<server>/mods/deathmatch/resources/` ثم شغّل `start NightCity` (MTA **1.6.0-9.22676 أو أحدث**).
2. داخل اللعبة اكتب **`/ncshow`**. تظهر المدينة على ارتفاع 900 م فوق الخريطة الأصلية؛ ويمكن استخدام `/ncshow here` أو `/ncshow x y z` لاختيار موقع آخر.
3. أوامر بيئة المدينة تعمل على جهاز اللاعب، ولا تحتاج إلى إعادة تشغيل المورد لتغيير الساعة أو الطقس.

| الأمر | وظيفته |
|---|---|
| `/ncshow [here \| x y z]` و`/nchide` | إظهار المدينة وإزالتها |
| `/ncz <م>` | ضبط ارتفاع المدينة |
| `/ncfx [0\|1\|2]` | 0 بلا معالجة، 1 تدرّج لوني خفيف، 2 التدرّج مع طبقة بلل خفيفة للأسفلت (الافتراضي) |
| `/ncexposure <0.3-4>` | ضبط تعريض المعالجة اللونية |
| `/ncweather <sunny\|partly\|cloudy\|overcast\|foggy\|mist\|drizzle\|rain\|storm\|afterrain\|clearnight>` | اختيار الطقس؛ المطر غير مفعّل افتراضياً. اختيار طقس جديد يلغي تجاوز المطر اليدوي |
| `/ncrain <0-1>` | تحكم يدوي بالمطر؛ شدته المرئية محدودة بسقف طبيعي. اختر طقساً عبر `/ncweather sunny` (أو طقس آخر) لإلغاء التجاوز |
| `/nctime <ساعة 0-23> [دقيقة]` أو `/nctime <اسم فترة>` | اختيار أي ساعة أو فترة من اليوم؛ ضبط الساعة يوقف الدورة تلقائياً |
| `/ncpreset <dawn\|sunrise\|morning\|noon\|afternoon\|golden\|sunset\|dusk\|night\|midnight>` | اختصار لاختيار وقت اليوم |
| `/nccycle <on\|off> [ثوانٍ لكل ساعة لعب]` | تشغيل/إيقاف دورة اليوم والليل؛ الافتراضي 60 ثانية لكل ساعة لعب (يوم كامل خلال 24 دقيقة) |
| `/ncview <نقطة>`، `/nctour`، `/ncfree` | الانتقال لنقطة، جولة كاميرا، أو كاميرا حرة |
| `/ncinfo` | عرض حالة المدينة والرسوم والطقس |

## نظام البيئة

* يبدأ المورد بسماء صافية ظهراً ومطر متوقف، ثم يشغّل دورة يوم/ليل تدريجية. يمكن للاعب تثبيت أي ساعة بالأمر `/nctime`، أو إعادة تشغيل الدورة بـ`/nccycle on`.
* تتضمن الأوقات الفجر والشروق والصباح والظهر والعصر والساعة الذهبية والغروب والشفق والليل ومنتصف الليل. تتغير السماء والشمس وألوان الإضاءة والضباب بالتوازي مع الوقت.
* توجد حالات طقس صافية وغائمة وضبابية وممطرة وبعد المطر. يتغير طقس GTA الأساسي بسلاسة مع تدرج السماء والضباب والرياح؛ المطر اختياري ومحدود الشدة، والأسطح تبقى جافة في الطقس الصافي.
* الشيدرَان مكتوبان بميزانية صغيرة لـ **ps_2_0**. مؤثر الأرض لا يستخدم انعكاسات فضاء الشاشة أو أخذ عينات متعددة؛ هذا مقصود لتفادي المستطيلات/المثلثات الكبيرة وأخطاء تجاوز تعليمات الشيدر على الأجهزة الأقدم.
* المطر والبلل والمؤثر اللوني إضافات بصرية فقط. الإضاءة والسماء والوقت والضباب والطقس تظل قابلة للتغيير حتى عند إطفاء `/ncfx`.

## محتوى المدينة وحدود المحرك

* مخطط موسّع إلى **14 × 14 قطعة** مع تقاطعات T ونهايات مسدودة وأحياء مختلفة، ونهر بستة جسور وطريقين سريعين ونفق.
* إضاءة المباني واللافتات والوهج والبخار مبنية من خامات وعناصر بسيطة مناسبة لمحرك San Andreas.
* لا يوفّر المحرك إضاءة عامة أو ظلالاً ديناميكية حديثة؛ بعض الإضاءة مخبوزة في النماذج. قد يختلف شكل السماء والسطوع باختلاف جهاز اللاعب.
* ترجمة الشيدر النهائية تعتمد على عميل MTA وكرت الشاشة. إن ظهر أي خطأ في الرسم، استخدم `/ncfx 0` مؤقتاً، وأرسل سجل `debugscript 3` بعد تحديث المورد وإعادة تشغيله.

## إعادة البناء والتحقق (اختياري)

```
cd NightCity/source
python3 build.py                  # يحتاج numpy و scipy و pillow
python3 validate.py               # فحوص هندسة وخامات ومخطط ونفق
python3 mta_lua_test_nc.py        # اختبارات Lua بواجهة MTA تجريبية، إن كانت التبعيات متاحة
```
