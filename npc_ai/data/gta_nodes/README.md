# Generated node data

Do not place invented grids or hand-authored replacement nodes here.

Run `../../tools/convert_nodes.py` from the resource root against legally extracted original GTA San Andreas `nodes0.dat` through `nodes63.dat`. The converter writes `manifest.json`, `area_<N>.json`, `validation_report.json`, and updates the `meta.xml` dynamic-file block.

The actual Rockstar node files and their converted graph chunks are intentionally not redistributed with this source repository.
