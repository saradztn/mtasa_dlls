# RoyalPalace AAA

خط إنتاج Python يولّد هندسة القصر والبيئة بصيغ RenderWare فعلية (DFF/COL/TXD)، ثم يجهز مورد MTA قابل للنسخ. أساس الحزمة المرفقة فُحص ملفاً ملفاً؛ أعيد استخدام مكتبة DragonFF (GPL-3.0+) ونظام هندسة/تضاريس/غرف/مواد/تحقق لأن فحصها أثبت وجود مولد كامل، لا مجرد أدوات شكلية. أُعيد ضبط المسارات والتعبئة وأضيفت بدائل خامات إجرائية صريحة لأن صور الخامات المنفصلة غير موجودة داخل ZIP.

## بناء Windows
1. ثبت Python 3.9 أو أحدث، مع تفعيل `python` في PATH واتصال إنترنت أول مرة لتنزيل المتطلبات من PyPI.
2. من هذا المجلد نفّذ `python build.py`.
3. انسخ `output/RoyalPalace` إلى `mods/deathmatch/resources/` ثم شغّل `start RoyalPalace` في MTA.

البناء ينشئ بيئة افتراضية محلية، ويولد الخامات و406 نماذج وملفات التصادم ومشهد 419 قطعة، ثم يبني مجلد مورد مرحلياً ولا يستبدل المورد النهائي إلا بعد نجاح التوليد والتحقق من XML. الناتج والتقرير `build-report.json`.

## داخل اللعبة
`/palace` يعرض قائمة الإرشادات. `/palace day` و`/palace night` يغيران الوقت والسماء والطقس محلياً. `/showp` يعيد إظهار القصر، و`/palacehide` يخفيه. مفاتيح الأرقام 1–6 تنقل إلى نقاط المعاينة (يمكن تغييرها في `client.lua`). التبديل محلي وغير ديناميكي؛ لا يدعي وجود ظلال أو انعكاسات PBR حقيقية. إيقاف المورد يعيد النماذج والتصادمات وعناصر العالم وإعدادات الطقس/السماء المحفوظة.

## تقنيات وحدود
المشهد يستخدم نماذج DFF وCOL وTXD بمواد mipmapped DXT1/DXT5، وتظليل لوني مخبوز على الرؤوس. لا توجد ادعاءات بخرائط PBR/Normal أصلية داخل محرك MTA. موقع المجمع واتجاهه وأبعاده محددة في `layout.py` و`terrain.py`؛ نظام الإحداثيات هو XYZ متري في عالم GTA، ومحول Blender غير مطلوب لهذا المسار. لا تتضمن الحزمة تشغيل MTA؛ لذلك لا يمكن التحقق من عرضها داخل اللعبة في بيئة البناء هذه. موارد MTA التي تحتاج صلاحيات لاستبدال النماذج تتطلب ACL المناسب.
